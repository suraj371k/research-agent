# Docs folder

Drop your fake/sample knowledge-base files here (`.md`, `.txt`, or `.pdf`).
Examples to add later:
- market_trends_2024.md
- internal_meeting_notes.md
- product_specs.md
- past_report_ai_industry.pdf

Then run:
```
npm run ingest
```
This builds the FAISS vector index from whatever is in this folder.
